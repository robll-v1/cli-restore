# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.

Participants should communicate constructively, respect differing viewpoints, and focus on what is best for the project. Harassment, discrimination, threats, personal attacks, and sharing private information without permission are not acceptable.

Report concerns privately to the project maintainers. Maintainers may remove comments, close issues, or restrict participation when behavior violates this standard.
